# agents.md — Reading Buddy

Instructions for coding agents working on this repo.

---

## What this is

**Reading Buddy** is a phonics PWA for one specific 4.5-year-old learner on iPad Safari (installed as a home-screen PWA). It teaches synthetic phonics + sight words through audio-first, icon-only child UI and a procedural 3D robot avatar.

**Target user constraints:** cannot read on-screen text; knows some letter names/sounds; needs huge touch targets; no fail states or competitive scoring.

---

## Non-negotiable rules (bugs if violated)

1. **Never use `speechSynthesis` for a letter SOUND or curriculum WORD.** All phonemes and words come from pre-made MP3 clips in `public/audio/`. TTS is only for full-sentence instructions and praise.
2. **No text the child must read.** Child-facing buttons use icons only. Text is allowed on parent-gated screens (Settings, ParentGate).
3. **No fail states** — no game over, timers, losable scores, or punitive feedback. Wrong answers → gentle retry + scaffold; child always finishes having succeeded.
4. **No lip-sync.** Robot mouth is a generic loop while audio plays — not phoneme-synced.
5. **Robot is procedural Three.js primitives only** — no GLTF/external 3D assets.
6. **No backend in the app** — no accounts, analytics, or network calls except loading local audio clips (and optional remote TTS for instructions).
7. **Touch targets ≥ 96×96 CSS px**, confirm on `pointerup`/`touchend`, not `touchstart`.
8. **Minimal dependencies** — do not add Redux, Tailwind, UI kits, or extra animation libs without explicit human approval.

## Architecture

```
Boot (audio unlock) → HomeMap → LessonRunner → ActivityHost → RewardScreen → HomeMap
                              ↘ ParentGate → Settings
```

| Layer | Location | Notes |
|-------|----------|-------|
| State | `src/store.ts` | Single zustand store; progress in `localStorage` key `reading_buddy_progress_v1` |
| Settings | `src/settings/parentSettings.ts` | Robot name, TTS backend/URL in `reading_buddy_settings_v1` |
| Curriculum | `src/curriculum/lessons.ts` | 12 lessons — **do not reorder sounds or edit pedagogy** |
| Activity builder | `src/curriculum/buildActivities.ts` | Deterministic §5 algorithm — implement exactly, no improvisation |
| Audio clips | `public/audio/<key>.mp3` | Generated by `npm run generate-audio` |
| Clip manifest | `src/curriculum/audioManifest.ts` | `getRequiredClipKeys()` — 140 keys |
| Clip → speech | `server/clip-speech.mjs` | SSML/IPA for sounds, plain text for words |
| Runtime audio | `src/audio/AudioService.ts` | `speakClip(key)` / `speakText(text)` / `stopAll()` |
| Robot | `src/avatar/Robot.tsx` | Reads `avatarState` + equipped parts from store |

### Audio key scheme

| Key pattern | Example | Runtime use |
|-------------|---------|-------------|
| `sound_<phoneme>` | `sound_s.mp3` | Letter sound |
| `word_<word>` | `word_sat.mp3` | Whole decodable word |
| `sight_<word>` | `sight_the.mp3` | Sight word |
| `blend_<word>` | `blend_sat.mp3` | Slow sounds then word (or fallback sequence in AudioService) |

## Getting started (agent)

```bash
npm install
cp .env.example .env          # AWS creds for audio generation
npm run generate-audio        # if public/audio/ is empty or stale
npm run verify-audio          # must pass before shipping
npm run validate-curriculum   # buildActivities sanity check
npm run dev
```

| File | Rule |
|------|------|
| `src/curriculum/lessons.ts` | Paste verbatim from spec; sound order is deliberate |
| `src/curriculum/buildActivities.ts` | Pure deterministic algorithm (§5); cap at 7 activities |
| `server/clip-speech.mjs` | IPA phoneme map for TTS generation |
| `scripts/generate-all-audio.mjs` | Primary clip generator — calls Polly directly |
| `scripts/lib/lessons.mjs` | Mirror of lessons for Node scripts (keep in sync with TS) |

If curriculum data changes in `lessons.ts`, also update `scripts/lib/lessons.mjs`.

## Activity types

| Type | Component | Success behavior |
|------|-----------|------------------|
| `LISTEN_SOUND` | `ListenSound.tsx` | Exposure only; always succeeds on continue |
| `PICK_SOUND` | `PickSound.tsx` | Tap correct letter; scaffold after 2 wrong |
| `TRACE` | `Trace.tsx` | Finger trace ≥80% of path |
| `BLEND` | `Blend.tsx` | Tap sounds + blend button; `wholeWordClipOnly` for fish/sock |
| `BUILD_WORD` | `BuildWord.tsx` | Drag/tap tiles into slots |
| `SIGHT_WORD` | `SightWord.tsx` | Learn then find among decoys |
| `REVIEW_GAME` | `ReviewGame.tsx` | 3–4 quick review taps |

`ActivityHost.tsx` handles success flow: stars, celebrate state, StarBurst, advance.

## Common agent mistakes (re-check before finishing)

- [ ] Used `speechSynthesis` for a phoneme or word clip → **remove it**
- [ ] Put words on child-facing buttons → **use icons + audio**
- [ ] Added timers, losable scores, or game-over → **remove**
- [ ] Loaded external robot GLTF → **use primitives**
- [ ] Synced mouth to phonemes → **generic talk loop only**
- [ ] Tap targets under 96px or firing on touchstart → **fix**
- [ ] Added Redux, Tailwind, or unapproved deps → **remove**
- [ ] Changed `buildActivities` pedagogy or lesson sound order → **revert**
- [ ] Forgot to update `scripts/lib/lessons.mjs` when changing `lessons.ts` → **sync**
